# 番茄正文检查清单

这份清单给 `novel-scene-writer` 用来压正文气味，不是固定模板。

## 先看这段在干什么

先确认四件事：

- 谁在场。
- 谁在主导。
- 这段要推进什么。
- 这段结束后，局面要变成什么。

如果这四件事说不清，先别急着堆字。

## 去 AI 味

优先删这些东西：

- 空泛总结。
- 过满的抒情。
- 连续解释人物心理。
- 没有动作支撑的情绪句。
- 用同一种节奏把整段写平。

常见问题：

- “气氛一下子变得微妙起来。”
- “他的内心掀起了波澜。”
- “这一刻，他终于明白了很多事情。”

这类句子不是绝对不能用，但默认先怀疑。

## 压句（默认短句）

短句是**基准**，长句是**特例**。默认做法：

- 一句只放一个重点。
- 能拆就拆。
- 连着三句都一个长度时，主动打散。
- 连续三句都超过 25 字 → 强制拆短，不接受"读起来不完整所以不拆"。
- 重要句短一点。
- 解释句少一点。
- 长句只留给两种场合：决断/爆发/顿悟的一口气瞬间；或复合信息句，且前后要有短句夹着。

优先保留：

- 动作。
- 反应。
- 结果。

次级保留：

- 修饰。
- 判断。
- 抒情。

拒绝：

- 文邹邹的长段抒情。
- 为了"显得优美"堆形容词。
- 开头来一句作者腔金句压场。

## 镜头感检查

让这段戏能被**拍出来**。

问自己：

- 这段有没有景别变化（远/中/近）？还是自始至终一个距离？
- 镜头跟谁？谁在看？看到了谁的反应？
- 能不能抓到至少一个动作 / 视线 / 声音 / 环境压迫做落点？
- 如果把这段剪成短视频，分镜头列得出来吗？

例如，"他很紧张"这种纯情绪判断句不成像，改成可拍到的东西：

- 他手指发僵。
- 茶杯磕了下桌沿。
- 那句狠话到嘴边，又压了回去。

三个短句 = 三个镜头，可以直接"剪"。

## 对白检查

每句对白都过一遍：

- 这句是谁才会说？
- 这句是不是太会解释？
- 这句说完，局面有没有变化？
- 这句前后有没有动作和反应托住？

如果一句对白拿掉后，剧情、关系、气氛都不变，这句大概率该删或改。

## 人物口吻

从这几处看：

- 身份高低。
- 年龄层。
- 文化程度。
- 当前情绪。
- 关系远近。
- 所处环境能不能让他说这么多。

同一句“你过来”，不同人物会有不同写法：

- 上位者会更短，更硬。
- 熟人可能更松。
- 心虚的人容易绕。
- 急的人会断。

## 场景张力

张力通常来自这些东西：

- 信息差。
- 关系失衡。
- 利益冲突。
- 时间压力。
- 环境压迫。
- 说不出口的话。

不要只靠大喊大叫做张力。

很多时候，少一句解释，多一个停顿，张力更高。

## 过渡段 / 场景切换

场景切换**不能突然**。过渡段不能只是把人送到下一个场景。

至少带一个东西过去：

- 新情绪。
- 新疑点。
- 新关系变化。
- 新风险。
- 新决定。

并且上一场要给下一场留"钩子"，下一场开头要"接住"钩子。三种合法钩子任选其一：

- **情绪钩子**：上一场末尾的情绪落点（指节/眼神/沉默）在下一场开头被接住。
- **疑点钩子**：上一场末尾没答的问题/没说完的话，在下一场第一段重新浮出来。
- **时间/空间钩子**：写出具体的时间/空间位移锚点（"三日后，同样的亭子，雪还没化"），不是干巴巴的"第二天"。

如果只是"吃完饭以后，他们去了公司"——这不是有效过渡，是硬切。

硬切红线（出现就回去改）：

- 用"另一边 / 与此同时 / 话说回来"当万能转场词，但上下没有平行叙事钩子。
- 高潮过后立即跳日常场景，紧张度瞬间清零。
- 新场景开头没有任何一句与上一场呼应。

## 最后复检

交稿前再问一遍：

- 读者能不能顺着读下去。
- 这一段有没有往前走。
- 人是不是像人。
- 话是不是像人话。
- 张力是不是比原稿高。
- **镜头出不出得来**——分镜头列得出来吗？
- **句子默认是短的吗**——连续三句长句没打断吗？有没有文邹邹长段？
- **场景切换有钩子吗**——上一场的情绪/疑点有没有被下一场接住？
