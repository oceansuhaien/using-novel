# 正文文风指南（番茄网文 × 小说大神风格）

供 `novel-scene-draft` / `novel-scene-polish` / `novel-scene-expand` / `novel-scene-rewrite` 共用。
**不是模板**，是写完、改完、扩完都要自查的一组气味与手感。

## 目标文风

写给**番茄网文的读者**看，学**小说大神**的手感：

- 好读、信息密度够、但不油腻。
- **镜头感强**，画面落得下来，情绪托得住，张力不靠喊。
- **句子默认短**——短句是基准，长句是特例。能一笔写透，绝不用三笔。
- 角色像人，对白像话，细节有落点。
- 不装腔、不说教、不作者腔评论，**不要文邹邹的长段抒情**。
- 不追求华丽辞藻——辞藻的上限是"准"，不是"美"。

## 三大核心

### 1. 镜头感（不只是画面感）

读者眼里要能**看到一段戏**，像在看电影，而不是只看到一个静态画面。把每段戏当镜头来写：

- **景别**：远景交代环境/人物位置 → 中景推进互动 → 近景/特写压紧情绪。一段戏里景别要有变化，不能自始至终同一距离。
- **运动**：谁动、怎么动、镜头跟谁。"他朝门口走去"是叙述；"他朝门口走。脚步一顿。没回头。" 是镜头。
- **切换**：视点切换（谁在看 → 看到了什么 → 被看者的反应）要清晰，不要在一句里同时塞三个人的内心。
- **剪辑感**：**短句 + 留白 + 行动 + 反应**替代长段心理描写。读者要能"剪"出节拍。

落点（镜头里要抓什么）：

- **动作**：手指发僵、茶杯磕桌沿、背对着人把刀插回鞘。
- **视线**：眼神停在哪里、第一个移开的是谁。
- **声音**：脚步轻重、器物声、风雪声、远处马蹄。
- **环境压迫**：雪停未化、柴火湿、人流稀——让空间替情绪说话。
- **身体反应**：呼吸、指节、喉结、颈侧血管，优先选"能被别人看见的"。

反例：`气氛变得微妙。` / `他感到内心掀起波澜。` / `空气仿佛凝固了。`
都只有概念没有镜头。能删就删，要保留就补一个物件/动作/声音做落点。

**自检一问**：如果把这段戏拍成短视频，分镜头列得出来吗？列不出来 → 写得太"作者腔"了，回去加动作、视线、声音。

### 2. 张力

张力不是吼出来的。张力来源按优先级：

1. **信息差**：谁知道、谁不知道、谁以为自己知道。
2. **关系失衡**：谁在压、谁在让、谁在装没事。
3. **利益冲突**：表面和平，桌下在撕。
4. **时间压力**：敌人在路上、天要亮、药还差一味。
5. **环境压迫**：封闭空间、异常天气、即将到来的第三个人。
6. **说不出口的话**：想问但不敢问，想认但不肯认。

优先用前三个，它们省字、耐读、让读者替角色紧。

默认做法：**少一句解释，多一个停顿**；高潮前压半拍再放；敌强我弱时写对方的"不着急"，敌弱我强时写我方的"不敢放松"。

### 3. 情绪

情绪必须落到身体和行为。**纯情绪词是 AI 味最重的来源**。把情绪转写成：

- **念头**（短、断、跳）：他想开口，没开。又想退一步，也没退。
- **身体反应**（优先能被别人看见的）：指节发白、指尖压桌面、脊背挺得比刚才直一点。
- **外部反应**（用旁人反应反过来映照）：茶棚老板悄悄把炭盆挪远了半步。
- **微动作克制**：想笑没笑，想骂咽回去——克制本身就是情绪。

反例：`她非常愤怒，怒火中烧。` / `他的内心五味杂陈。` / `他终于明白了很多事情。`

## 文笔手感

### 节奏

- 一段只打一个拍子。动作段短句密，叙述段可长一点，情绪段要留白。
- 连着三句同长度 → 主动打散。
- 重要句压短，解释句让位。
- 对白和动作交替，不让一个人连说五句对方只听着。

### 句子与用词

**默认铁律：短句优先。**

- **长句是例外，不是常态。** 默认就写短句——一句一个重点，读起来像节拍。
- 长句**只**保留给两种场合：（a）需要一口气读完的瞬间（决断、爆发、意识到真相）；（b）交代必要信息时的复合句，且必须前后被短句夹着。
- 连续三句都超过 25 字 → 强制打散，哪怕拆出来的短句单独看不那么"完整"。
- 优先具体名词 + 具体动词。形容词、副词节制。
- 不堆成语，不用"万能情绪词"（震惊、愤怒、复杂）。
- 不追求辞藻华丽；**辞藻的上限是"准"，不是"美"**。
- 不写文邹邹的长段抒情；抒情要落到一个具体的物件、动作、声音上。
- 人物口吻按"身份 + 年龄 + 情绪 + 关系 + 所处环境"走：上位者短硬，熟人松，心虚者绕，急者断。

### 对白四问

每句对白过一遍：

1. 这句是谁才会说？
2. 是不是在替作者解释？
3. 说完，局面有没有变？
4. 前后有没有动作/反应托住？

一句对白删了剧情、关系、气氛都不变——这句大概率该删或改。

## 长度观

**不设硬字数上限**。

- 场景长度由节奏、情绪曲线、张力释放点决定。
- 不为"凑够"堆空段，不为"压缩"砍关键动作和过渡。
- `intent.length_hint` 存在时作为**参考口径**，不是硬门槛；可以偏离，但偏离要服务意图。
- 写完自问：**这个长度是故事需要的，还是我懒 / 贪出来的？**

## 气味红线（一出现就停下来改）

- 空泛总结句（"气氛变得微妙"、"一切都不一样了"）。
- 成套修辞堆叠（"犹如……仿佛……宛若……"）。
- 连续解释人物心理、没有任何外部动作落点。
- "感到 / 觉得 / 似乎 / 仿佛 / 好像" 串联整段。
- 作者腔评论（"这就是命运的残酷"、"或许这就是爱"）。
- 华丽排比连发三句以上。
- 高潮段靠形容词，不靠动作结果。
- 对白全员会说人话但没人像自己。
- 过渡段只搬人物位置（"吃完饭以后，他们去了公司"）。
- **场景硬切**：上一场的张力 / 情绪 / 疑点没有任何承接就跳到下一场。
- 连续三句长句（>25 字）无短句打断。
- 文邹邹的整段抒情、作者发表人生感悟、段落开头来一句"金句"压场。

## 场景切换：承上启下不能断（硬要求）

场景切换**不能突然**。下一场开头之前，上一场必须留下至少一个"钩子"往下带；下一场开头必须"接住"这个钩子。

### 三种合法切换写法

1. **情绪钩子**：上一场末句定住一个情绪落点（指节/眼神/沉默），下一场开头用相同情绪基调或同一身体反应接住。
2. **疑点钩子**：上一场末尾留一个没答的问题 / 没说完的话 / 没查清的人，下一场第一段就让这个疑点浮出来（不一定解答，但要让读者知道"它还在"）。
3. **时间/空间钩子**：明确写出时间或空间的位移锚点（"三日后，同样的亭子，雪还没化"），不能只写"第二天"。

### 禁止

- 禁止纯位置切换（"吃完饭后他们回家"、"几天后"然后没头没尾开始新戏）。
- 禁止切换时丢掉上一场留下的紧张度——高潮后可以缓，但不能瞬间"清零"。
- 禁止用"话说回来" / "另一边" / "与此同时" 当万能转场词，除非真是平行叙事并且两头都有钩子。

### 过渡段本身也要带东西

过渡段必须至少带一样东西过去：**新情绪 / 新疑点 / 新关系变化 / 新风险 / 新决定**。只换地点不带东西 → 不是过渡，是注水。

## 交稿前复检

- 读者能不能顺着读下去？
- 这一段有没有推动故事？
- 人像不像人？话像不像这个人说的话？
- **镜头出不出得来？** 如果拍成短视频，分镜头能列出来吗？张力是不是比原稿高？
- **句子是不是默认短？** 有没有连续三句长句没打断？有没有文邹邹的长段抒情？
- **场景切换有没有钩子？** 上一场的情绪/疑点有没有被下一场接住？有没有"突然"到下一场？
- 情绪有没有落到念头 / 身体反应 / 外部反应？
- 有没有空泛总结句漏网？
- 有没有地方是为了"凑长度"或"压长度"写的？有就改掉。
