# Novel Directory Contract

`.novel-skill/` stores story-development data. Unless the user specifies another path, use this layout:

```text
.novel-skill/
  README.md
  summary.md
  outline/
    premise.md
    volumes.md
    worldbuilding.md
  plot/
    mainline.md
    hidden-threads.md
    foreshadowing.md
    beats.md
    volume-hooks.md
  characters/
    index.md
    cards/
    relationships/
  chapters/
    notes/
    extracts/
  canon/
    timeline.md
    factions.md
    locations.md
  inbox/
    raw-ideas.md
    unresolved-questions.md
```

## Placement Rules

- `summary.md`: stable high-level project state, current conclusions, and open questions.
- `outline/`: premise, volume structure, story spine, and longform outline material.
- `plot/`: mainline, beats, hidden threads, foreshadowing, reversals, and volume hooks.
- `characters/`: character cards, roster, relationships, arcs, secrets, and character-bound rules.
- `canon/`: world rules, factions, locations, timeline, systems, and durable setting facts.
- `chapters/`: chapter-level observations, notes, extracts, and evidence-like material.
- `inbox/`: raw ideas, alternatives, unresolved questions, and not-yet-confirmed material.

Keep `summary.md` concise. Do not store long character cards, beat sheets, chapter extracts, or relationship analysis there when a more specific directory exists.
