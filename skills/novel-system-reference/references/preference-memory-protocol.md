# 偏好记忆协议

本协议用于管理 `using-novel` 及其 routed 子技能共享的**作者写作偏好记忆**。

它不是 `context.md` 的替代品，也不是第二份 `summary.md`。它负责的是：
- 哪些写作经验可以跨书复用
- 哪些规则只对当前书生效
- 新归纳的经验何时只是提醒，何时可以升级为稳定规则
- 什么级别的问题允许直接拦截，什么级别只能提醒

## 双层规则

### 作者级

作者级偏好经验面向**跨书复用**。

适合放在作者级的内容：
- 明确反感的高概率毒点
- 明确偏好的爽点或写法
- 可泛化的创作范式，例如：
  - 人物反常行为要有足够前因或关系支撑
  - 新人物出场应给足识别锚点
  - 人物明显变化不能空白带过

作者级规则要尽量短，能被多个任务复用。

### 单书级

单书级推理规则**只对当前书生效**。

适合放在单书级的内容：
- 当前书的人设一致性约束
- 当前书的环境与资源条件约束
- 当前书的城市规模、阶层、势力、时间线对人物行为的限定

单书级规则不能机械套模板，必须允许结合人物身份、性格、关系、环境压力、城市等级、剧情位置等上下文做推理。

## 状态分层

### 候选经验

候选经验来自：
- 当前产出中暴露出的重复问题
- 用户对本轮文本的负反馈或正反馈
- 串行补全扫描中识别出的高相关模式

候选经验默认只作为软提醒存在：
- 可以进入后续任务的检查清单
- 可以在复盘时被再次引用
- 不能自动升级为稳定规则

### 稳定规则

稳定规则必须经过用户确认后生效。

稳定规则一旦成立：
- `using-novel` 任务前应默认读取
- routed 子技能应消费最短相关摘要
- 后续命中时可作为正式约束参与提醒或拦截

## 拦截门槛

只有满足以下条件，系统才允许直接拦截当前输出：
- 命中的是稳定规则，或高置信候选经验
- 能指出违反了哪条已知设定、哪段上下文、哪类高概率毒点
- 能说明理由，并形成清晰证据链

如果只是模糊感觉不对：
- 只能提醒
- 不能直接拦截

## token 边界

偏好记忆的长期内容必须保持**短格式**，目标是节约 token，而不是保存长篇分析。

建议原则：
- 一条经验尽量压成一到三句
- routed 子技能默认只读取**最短相关摘要**
- 长推理过程放在本轮分析或章节级证据里，不直接塞进长期记忆

## 与其他协议的边界

- `context.md`：记录单书共享决策、冲突、覆盖历史，不负责承载完整作者级偏好体系
- `summary.md`：记录高层稳定状态，不负责承载细粒度偏好协议
- 章节级执行审计：负责记录本轮为什么命中或未命中某条经验，但不等于长期偏好记忆本体

## 最小消费规则

任务前：
- 读取作者级稳定规则
- 读取当前书单书级稳定规则
- 必要时补充高相关候选经验

任务后：
- 从产出和用户反馈中提炼候选经验
- 判断它应进入作者级还是单书级
- 判断它是否值得进入后续提醒清单

用户确认后：
- 才允许把候选经验升级为稳定规则
