# `summary.md` 推荐结构

`summary.md` 应长期保持"高层稳定信息页"的定位——只保存当前项目最重要、最稳定、最需要快速回看的内容。详细人物卡、关系网、章节摘录、长篇设定展开应下沉到对应小说架构模块。

整体目录契约见 `novel-driver:novel-system-reference/references/directory-contract.md`；本文件只负责 `summary.md` 内部的区块模板。

## 推荐区块

### 项目快照

- 书名：待定
- 题材：待定
- 频道/风格：待定
- 核心卖点：待定
- 一句话简介：待定
- 当前阶段：灵感整理 / 大纲搭建 / 卷纲细化 / 正文连载

### 核心主旨

贯穿全书的思想与价值母题（Theme）。这是作者价值观层的内容，和"核心承诺"分开写。

- 主旨一句话：待定（例："人是为活着本身而活，而非为活着之外的任何事物"）
- 反命题：待定（主角中途可能被迫直面、甚至短暂投向的对立信念）
- 结局如何回应：兑现 / 反证 / 留白（必须选一个，并给一句话说明）
- 承载主旨的主要剧情压力：待定（主线的哪一类冲突会正面逼出这个母题）
- 状态：草稿 / 待压测 / 已确认

主旨的长论述（超过两三句）写入 `outline/premise.md`，不要堆在这里。

### 核心承诺

读者市场/情绪层的承诺。和"核心主旨"区分开，不要合并。
