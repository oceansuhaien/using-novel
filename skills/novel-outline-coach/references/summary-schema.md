# Summary Schema

`.novel-skill/summary.md` 应长期保持“高层稳定信息页”的角色。

它保留项目当前最重要、最稳定、最需要快速回看的内容；详细角色卡、关系网、章节摘录、长篇设定展开，应下沉到 `.novel-skill/` 的对应子目录，而不是继续堆进 `summary.md`。

## Recommended `.novel-skill/` Structure

```text
.novel-skill/
  README.md
  summary.md
  outline/
    premise.md
    volumes.md
    worldbuilding.md
  characters/
    index.md
    cards/
      角色名称.md
    relationships/
      main-relationships.md
  chapters/
    notes/
    extracts/
  canon/
    timeline.md
    factions.md
    locations.md
  inbox/
    raw-ideas.md
    unresolved-questions.md
```
